# بسته آماده‌سازی انتشار سایت علی عظیمی و جهان‌نما

## ساختار فعلی
- `/` صفحه اصلی
- `/about/` درباره من
- `/jahan-nama/` معرفی جهان‌نما
- `/jahan-nama/submit/` فرم ثبت خواسته (نسخه پیش‌نمایش)
- پنل مدیریت عمداً در بسته عمومی قرار نگرفته است و باید جداگانه پشت احراز هویت واقعی منتشر شود.

## انتشار آزمایشی
1. محتویات این پوشه را در یک مخزن GitHub قرار دهید.
2. در Cloudflare Pages یک پروژه بسازید و مخزن را متصل کنید.
3. برای سایت HTML ساده، Build command را خالی بگذارید و Build output directory را ` / ` (ریشه مخزن) انتخاب کنید؛ اگر داشبورد مقدار `.` می‌خواهد، همان را وارد کنید.
4. پس از انتشار، مسیرهای بالا را در موبایل و دسکتاپ آزمایش کنید.

## موارد ضروری پیش از انتشار نهایی
- دامنه اصلی هنوز مشخص نشده؛ بنابراین canonical و sitemap.xml عمداً ساخته نشده‌اند. پس از تعیین دامنه، آدرس canonical هر صفحه و sitemap با URLهای واقعی ساخته شود.
- فرم موجود در این بسته پیش‌نمایش است و داده‌ها را به پایگاه داده واقعی نمی‌فرستد. برای دریافت درخواست واقعی، ابتدا بک‌اند و پایگاه داده را راه‌اندازی و فرم را به endpoint امن متصل کنید.
- پنل مدیریت عمداً از بسته عمومی حذف شده است. آن را فقط پس از پیاده‌سازی احراز هویت واقعی و کنترل دسترسی، جداگانه منتشر کنید؛ `noindex` و `robots.txt` جایگزین کنترل دسترسی نیستند.
- صفحات خدمات فرعی و مقالات هنوز آماده نیستند؛ لینک آن‌ها نباید به صفحه خالی یا 404 منتهی شود.
- تصاویر OG باکیفیت، favicon، اطلاعات تماس تأییدشده و محتوای نهایی را اضافه کنید.
- پس از انتشار: Google Search Console را متصل کنید، sitemap را ثبت کنید و URLهای مهم را بررسی کنید.

## نکته فنی
این بسته نسخه استاتیک قابل انتشار برای ارزیابی ظاهر و ساختار است؛ به معنی استقرار آنلاین یا فعال بودن پایگاه داده و API نیست.
